# Publishing the corrected acquisition-level revision to GitHub

The repository replaces the obsolete leave-one-`NODO` implementation with grouped
cross-validation over complete acquisition CSV files.

## Recommended clean replacement

From a local checkout of `AneddaM/firetransformer-2026`:

```bash
git checkout main
git pull

git checkout -b acquisition-grouped-cv
```

Replace the tracked repository contents with the contents of the revised package,
keeping `.git/` untouched, then run:

```bash
git status
git add -A
git commit -m "Replace LONO with acquisition-level grouped CV"
git push -u origin acquisition-grouped-cv
```

Review the diff on GitHub and merge the branch into `main`.

## After publication

A fresh clone should pass:

```bash
pip install -e .
python tests/smoke_test.py
```

On the real dataset run:

```bash
python scripts/dataset_audit.py --data data/raw --strict-public
python scripts/cv_preflight.py --data data/raw --output runs/preflight
```

Do not publish results generated by the obsolete `run_lono.py` protocol.
